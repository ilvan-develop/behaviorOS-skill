## 4. Authority Chain

### Decision Plane

```
governance-state.json
        │
        ├── SOURCE OF DECISION
        ├── TTL-based entries
        ├── Session-scoped
        ├── Gate-specific
        └── O(1) lookups
              │
              ▼
        oage-enforce.js
              │
              ▼
         ALLOW / DENY
```

### Evidence Plane

```
current.jsonl
        │
        ├── SOURCE OF EXPLANATION
        ├── Bounded (10MB / 10K events)
        ├── Append-only
        └── O(n) reads
              │
              ▼
        readAuditWindow()
              │
              ▼
           rotation
              │
              ▼
         archive/YYYY/MM/
```

### Observability Plane

```
reconciliation.js
        │
        ├── OBSERVATIONAL ONLY
        ├── Detects inconsistencies
        ├── Reports health status
        └── Never authorizes
              │
              ▼
      SYNCED / MISSING_AUDIT / STATE_AHEAD
      AUDIT_CORRUPTED / STATE_CORRUPTED
      RECONCILIATION_FAILED
```

### Authorization Rules

| Source | Can Authorize? | Rationale |
|--------|---------------|-----------|
| governance-state.json | ✅ YES | Sole authority for decisions |
| audit.jsonl | ❌ NO | Explanation only, not authorization |
| reconciliation.js | ❌ NO | Observational only, not authorization |
| archive/ | ❌ NO | Historical evidence, not authorization |

## 9. Architectural Decisions

| Decision | Rationale | Documented In |
|----------|-----------|---------------|
| Governance state is SOURCE OF DECISION | Audit trail is append-only, O(n) reads, grows unboundedly. State is bounded, O(1) lookups. | `P1.2-AUDIT-GOVERNANCE.md` |
| TTL over event count for freshness | "Last 50 queries" does not capture temporal degradation. A query from 2 hours ago should not satisfy a gate today. | `P1.2-AUDIT-GOVERNANCE.md` |
| Fail-closed over fail-open | Fail-open means corruption permits any operation. Fail-closed blocks until valid evidence is provided. | `P1.2-AUDIT-GOVERNANCE.md` |
| Three-plane separation | Decision, Evidence, Observability planes must not overlap. Lower planes never usurp upper planes. | `P1.2-CLOSURE-EVIDENCE.md` |
| Reconciliation is observational | Reconciliation detects inconsistencies but never authorizes operations. | `reconciliation.js` |
